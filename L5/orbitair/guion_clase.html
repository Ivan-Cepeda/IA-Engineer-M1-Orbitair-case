Cómo ejecutarla

Estrategia progresiva: un archivo, una corrida, una pregunta

La clase avanza en el orden del pipeline. En cada bloque se escribe un archivo, se corre un paso con python clase5.py --hasta=5.x y se cierra con una pregunta a la clase. Nunca se escribe código que todavía no se pueda ejecutar.

Hay dos redes de seguridad. test_metricas.py prueba las métricas sin gastar nada. --sin-api recalcula todo desde los .jsonl ya guardados, así que si en vivo falla la red o la cuota, la clase sigue con la corrida anterior.

Exact match y LLM-as-judge

5.3exact match
def exact_match(categoria_modelo, categoria_referencia) -> bool:
    if categoria_modelo is None: return False          # sin categoría = error, no se descarta
    return categoria_modelo.strip().lower() == categoria_referencia.strip().lower()

def evaluar_exact_match(registros) -> dict:            # global Y por categoría
Por qué

La categoría tiene forma cerrada: o es equipaje o no lo es. Exact match es gratis, instantáneo y da siempre lo mismo. El desglose por categoría es lo que muestra el problema: v1 tiene 63 % de total, pero otros da 0 %.

Por qué

La idea

Que exact match y el juez no coincidan no es un bug de ninguno de los dos: miden cosas distintas. La pregunta útil es qué dice cada discrepancia sobre ese caso. Si el juez no coincidiera con el humano, el problema estaría en el juez, no en los prompts.

Umbral, costo por acierto y reporte

Archivos: metricas.py · reporte.pyDemo: --sin-api --hasta=5.5 · --sin-api
5.5umbral
UMBRAL_MINIMO = 0.70   # por categoría — fijado ANTES de correr nada

def chequear_regresion(scores_por_categoria) -> list[str]:
    return [c for c, s in scores_por_categoria.items() if s < UMBRAL_MINIMO]
Por qué

“v2 acierta 93 %” no dice nada sin un piso. Regresión, en su forma más simple, es una categoría por debajo del umbral. La comparación contra una corrida anterior, con margen de ruido, queda para más adelante.

Experimento

Subir el umbral a 0.85 y correr --sin-api --hasta=5.5. v2, v3 y v4 caen por equipaje (83 %). Sin llamar al modelo, la decisión cambia. Por eso el umbral se fija antes.
